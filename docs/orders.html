What the columns mean

Memorized: of the 14 wheel turns, how many need a memo formula; the rest are intuitive (line clocks up by eye; expand a row to see which clocks go with which).

Memo: a formula's length is the number of clocks you add up to get that turn. Shorter is easier to memorize.

D-wheel: pin states whose front move is on a D wheel (U, D, DL, DR, dl, dr), which some people find awkward.

Pin changes: how many pins you flip between consecutive pin states. Fewer means faster hands.

The numbers are generated by scripts/build-orders.js, a port of the statistics loop in ClockClean.Rmd, and stored as plain CSV in docs/data/orders/ (one file per pin set).
